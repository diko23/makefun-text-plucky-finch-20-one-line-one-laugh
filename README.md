## About the entry

A standalone observational one-liner built around a short, unexpected physical-versus-mental reversal on everyday comfort gear, kept tight and self-contained to land cleanly in one pass without prior setup.

## Run it

```sh
node main.ts
```

The program writes the single-line UTF-8 entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaulting to `/output/entry.txt`, as run by the grader via `node /bot/main.ts`), sets permissions to `0644`, prints nothing on success, and exits non-zero on failure.
